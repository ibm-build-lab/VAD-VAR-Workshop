# Lab Preparation Guide

## Step 1: Create an IBMid and IBM Cloud Account

### 1.1 Create Your IBMid
1. Go to [IBM Account](https://www.ibm.com/account/us-en/).
2. Click **Log in to My IBM**.(A)
   ![login](../images/210/login.png)
3. Click **Create an IBMid**.(A)
   ![create](../images/210/create.png)
4. Enter the following details:
   ![info](../images/210/info.png)
   - Email(A)
   - First name(B)
   - Last name(C)
   - Password(D)
   - Country(E) & State(F)
   - Company (Optional)(G)
5. Click **Next**(H).
6. verify your email, and finish account creation by entering **Verification token** (A) and click **Create account**(B).
   ![auth](../images/210/auth.png)
7. The About your IBMid Account page is shown. Click **Proceed**. 
7. After activation, your IBMid is ready.(may take a few mins)

### 1.2 Create an IBM Cloud Account
1. If you don’t have an IBM Cloud account, go to [IBM Cloud Registration](https://cloud.ibm.com/registration).
2. Follow the instructions sent over email to activate your account after registration.

## Step 2: Provision the SaaS Environment

### 2.1 Request a watsonx.ai Environment
1. Navigate to the [IBM TechZone](https://techzone.ibm.com/collection/data-and-ai-technology-sales-enablement/journeywatsonx-technical-enablement).
    ![itz](../images/210/itz.png)
2. Click **IBM Cloud Environment**(A) on the **“watsonx Discovery with Assistant, AI and Speech”** tile.
    ![itz-create](../images/210/itz-create.png)
3. Click **Reserve a Environment**(A) and complete the reservation form:
    ![reserve](../images/210/reserve.png)
   - Click education tile.(A)
   - Purpose description (e.g., "Using the environment for course work")(B)
   - Select **Preferred Geography**.(C)
   - Agree to the Terms and Conditions(D) and click **Submit**(E).
    ![reserve-details](../images/210/reserve_details.png)

### 2.2 Receive Confirmation
- After submission, you'll receive several emails:
  1. A confirmation email.
  2. Updates about environment provisioning.
  3. A final **“Ready”** email with the account number(A).
    ![reservation-ready](../images/210/ready.png)
  4. You may also receive an invitation to join the IBM Cloud account used by TechZone. Accept it to access your environment.
    ![invitation](../images/210/join.png)
  5. Click **Join now**.Follow the steps in the emails from IBM Technology Zone to connect to your environment.

## Step 3: Gather watsonx.ai API Details

### 3.1 Launch watsonx.ai Studio
1. Log in to [IBM Cloud](https://cloud.ibm.com).
   ![check](../images/210/cloud-itz.png)
2. Switch to the account mentioned in the **“Ready”** email(A).
3. Open **watsonx.ai Studio**(W) from your resource list.
   ![resource](../images/210/resource.png)
4. On the resource Manage page, open "Launch In >", then select "IBM Watsonx" (X):
   ![Launch](../images/210/launch.png)
   


### 3.2 Create a New Project
1. Switch to the account indicated in the environment Ready email (A). Click the **plus (+)** icon on the Project pane, create a new Project.
    ![Sandbox](../images/210/sandbox.png)
2. Follow the prompts to set up your project.

### 3.3 Verify watsonx.ai Runtime Association
1. In **watsonx.ai Studio**, go to your **sandbox project**(A).
    ![](../images/210/created-sandbox.png)
2. Under the **Manage** tab(M), navigate to **Services and Integrations**(S).
    ![manage](../images/210/manage.png)
3. Within the **IBM Services** pane (I), verify that **watsonx.ai Runtime** (R) is associated.
4. If the previous step did not show an associated **watsonx.ai Runtime**, click **Associate service** (A).
    ![Associate Service](../images/210/associate.png)
• Within the Associate service window, select the **watsonx.ai Runtime Service** (R) then **Associate** (A).
    ![Associate Runtime](../images/210/runtime.png)

### 3.4 Create an API Key
1. Go to [IBM API Keys](https://cloud.ibm.com/iam/apikeys).
2. Click **Create +** to create a new API key.
3. Select **No** for "Will this API key create a session in the CLI.
4. Download the **API key JSON**.

### 3.5 Gather Project ID and API Endpoint URL
1. Visit [Developer Access](https://dataplatform.cloud.ibm.com/developer-access?context=wx).
2. Switch to the correct account.
3. Get the details :
   ![Developer Access](../images/210/developer-access.png)
   - From the **watson.ai URL (U)** field, copy the API URL.
   - In the dropdown Location (L), select **“Project”**. 
   - In the dropdown **Project (P)**, select the name of the Project created in the last step
   - From field **Project ID (I)**, copy the unique Project ID.
