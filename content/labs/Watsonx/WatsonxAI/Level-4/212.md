# Part Two: AutoAI RAG Using a Jupyter Notebook

In this part of the lab, you will use a Jupyter Notebook to perform AutoAI RAG. Here’s the information you need to gather for the notebook:

| **Field**                           | **Description**                                    |
| ----------------------------------- | -------------------------------------------------- |
| **API Key**                         | Your Watsonx.ai API key                            |
| **Project ID**                      | Your Watsonx.ai Project ID                         |
| **Cloud Object Storage Bucket**     | The name of the Cloud Object Storage bucket        |
| **Granite 3.0 PDF**                 | The uploaded Granite 3.0 PDF in the Cloud Storage  |
| **Access and Secret key**           | The access and secret key credentials              |
| **Cloud Object Storage Connection** | The Data Connection ID to the Cloud Object Storage |
| **Milvus Vector Store Connection**  | The Data Connection ID to the Milvus vector store  |

## Creating a Connection to the Cloud Object Storage Bucket
### 1. Add the Connection
1. From **main menu**, go to **watsonx** and launch **watsonx.ai**.
2. Go to the **project** section and open **notset's sandbox**.
3. Click the **Assets** tab(**A**) and select **New asset**(**B**).
   ![](../images/212/asset-sand.png)
4. In the 'What do you want to do' search bar, search for **Connect to a data source**(**C**) and select the same below(**D**).
   ![search](../images/212/search-connect.png)
5. Go to **Add connection** in watsonx.ai.
6. In the search field, type: **IBM Cloud Object Storage**(**E**).
7. Select the **IBM Cloud Object Storage**(**F**) tile (either from main area or sidebar).
8. Click **Next**(**G**).
   ![Add connection](../images/212/add-connection.png)

### Configure the Connection

9. On the *Connect to a data source: IBM Cloud Object Storage* page:
    - **Do NOT select an instance**(**A**).
    - Fill in the following fields:
      - **Name**: **COS_connection** (**B**)
      - **Bucket**:Enter the value of **Cloud Object Storage Bucket ID** (**C**). 
      - **Login URL**: Enter the value of **Public Endpoint** (**D**). 
      - **Authentication method**: Select **Access key and Secret key** (**E**.)
      - **Access key**: Enter the value of **access_key_id** (**F**).
      - **Secret key**: Enter the value of **secret_access_key** (**G**).

10. Click **Test connection** (**H**).
    ![connect-details](../images/212/connect-details.png)

### 3. Finalize the Connection

7. If the test is successful, click **Create** on the bottom.
8. When prompted with *Create connection without setting location and sovereignty*, click **Create** again.

11. Record the Connection ID in your tracking table.
12. Click **Cancel** to close the window.
